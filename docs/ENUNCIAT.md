## 29. Disseny + programació

Crea des de zero, en local, la web corporativa d'una empresa (inventada o real) amb l'última versió estable d'Angular, Bootstrap i Laravel (PHP 8.2 o superior). Resumint, cal crear un projecte web des de zero al teu portàtil (desenvolupament tot en localhost, no cal cap servidor extern)

Temps d'entrega: 1 setmana

L'exercici consisteix en crear la pàgina corporativa d'una empresa (la que tu vulguis) a través de views/blades de Laravel, però també a través de views html que utilitzin Angular.

En principi no cal connexió a cap base de dades, però es valorarà de manera important si una part de la web recupera el seu contingut d'una base de dades

Es valorarà també l'estètica i disseny (scss/css), clean code, qualitat dels commits i documentació.

Es podran demanar petits canvis en directe durant la revisió remota

Pots posar els textos i fotos que et convingui

**Lliurament:**

- Repositori Git (GitHub/GitLab) amb l'historial de commits.
- README amb els passos d'instal·lació, un .env.example i captures de pantalla.
- Declaració d'ús d'IA: quines eines has fet servir, per a què, i 2 o 3 prompts representatius. L'ús d'IA no penalitza; es valora la transparència i el criteri.
